# 📰 Fake News Detection

A Machine Learning project that detects whether a given news article is **Fake News or Real News**.

The project uses **Natural Language Processing (NLP)** techniques to process the news text and a Machine Learning model to make predictions.

## 🚀 Demo

👉 **Live Demo:** [Fake News Detection App](https://fake-news-detection-eiavoqgpxtkmk27eqs3juw.streamlit.app/)


## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* NLTK
* Streamlit
* NLP
* Machine Learning

## 🔍 How It Works

1. User enters a news article.
2. The text is cleaned and preprocessed.
3. Stopwords are removed.
4. Stemming is applied using NLTK.
5. The processed text is converted into numerical features.
6. The trained Machine Learning model predicts whether the news is **Fake** or **Real**.
